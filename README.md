# 手机文件共享（LanFileShare）

<div align="center"><img src="docs/logo.jpg" width="140" alt="logo"/></div>

把安卓手机变成一台**局域网文件服务器**：手机上启动服务后，同一局域网内的电脑用浏览器打开 `http://手机IP:8080`，即可收发文件，无需在电脑上安装任何软件（适合受限的公司电脑）。

## 功能

**网页端（电脑浏览器 Chrome/Edge 等）**
- 浏览共享目录，面包屑导航、返回上一层
- 上传文件 / 上传整个文件夹（也支持拖拽文件或文件夹到页面直接上传，带进度条）
- 新建文本文件，并可在线编辑、保存（把文字内容直接传进手机）
- 新建目录、重命名、删除（含文件夹递归删除，删除前有确认）
- 下载单个文件；文件夹/多选**打包 zip 下载**（zip 内中文文件名在 Win10/11 资源管理器中正常显示）
- 勾选多个文件/文件夹：批量打包下载、批量删除
- 当前页面内搜索过滤；按文件名/大小/修改时间排序
- 点击图片/视频/音频可在线预览播放；点击文本文件直接在线编辑

**手机端**
- 启动/停止服务（前台服务 + 常驻通知，通知里可一键停止）
- 内置目录选择器，可共享手机存储里的任意文件夹
- 显示电脑访问地址（`http://IP:8080`），点击复制
- "保持唤醒"开关（默认开）：锁屏后服务不中断
- 免密码访问（局域网内可直接操作），请只在可信网络中使用

## 用 GitHub 编译 APK（无需本地安装任何开发环境）

1. 登录 [github.com](https://github.com)，右上角 **+** → **New repository**，起个名字（如 `LanFileShare`），选 Public（Private 也可以，但下载 artifact 需登录），创建。
2. 把本项目上传到仓库，两种方式任选：
   - **网页上传**：仓库页点 **uploading an existing file**，把 `LanFileShare` 文件夹**整体拖进**浏览器（注意拖的是文件夹里面的内容结构，保证 `.github`、`app` 等目录都在仓库根下），点 **Commit changes**。
   - **git 命令**：
     ```bash
     cd LanFileShare
     git remote add origin https://github.com/<你的用户名>/<仓库名>.git
     git push -u origin main
     ```
3. 打开仓库的 **Actions** 标签页，等 "Build APK" 工作流跑完（约 3~5 分钟）。
4. 进入该次运行页面，底部 **Artifacts** 下载 `app-debug-apk`，解压得到 `app-debug.apk`。
5. 以后改了代码再 push，会自动构建新版本。

> 说明：构建时缓存了 debug 签名文件，因此**后续版本的 APK 可以直接覆盖安装升级**（无需先卸载）。

## 安装与使用

1. 把 `app-debug.apk` 传到手机（微信文件传输助手/数据线/网盘均可），安装（需允许"安装未知应用"）。
2. 打开 App：
   - 首次使用点 **去授权「所有文件访问」**，在系统设置里允许后返回（安卓 7~10 为弹窗授权存储权限）。
   - 点 **选择共享目录**，选中要共享的文件夹（如 `Download`、相册、微信文件夹等）。
   - 点 **启动服务**。
3. 电脑浏览器输入 App 上显示的地址，例如 `http://192.168.1.5:8080`。

## 常见问题

**电脑打不开网页？**
- 确认手机和电脑连的是**同一个路由器**（同一网段）。
- 公司 Wi-Fi 若开启了 **AP 隔离**（设备间禁止互访），网页将无法访问。替代方案：
  - 手机开**个人热点**，电脑连手机热点；
  - 或手机用 USB 数据线开启 **USB 网络共享**，电脑即可通过该连接访问手机（此时 App 会显示一个 `192.168.42.x` 之类的地址）。
- 手机锁屏休眠后 Wi-Fi 可能断开：保持 **保持唤醒** 开关打开，并尽量插着充电器。

**IP 地址变了？** 以 App 页面上实时显示的地址为准。

**8080 端口被占用？** 关闭占用该端口的其它应用后重新启动服务。

**上传大文件？** 支持流式上传/下载，理论大小仅受手机存储限制；上传进度条显示整体进度。

## 安全提示

本应用为**免密码模式**，局域网内任何人都可以浏览、上传、删除共享目录内的文件。请只在家庭/可信网络中使用，不要在公共 Wi-Fi 开启，不要共享包含隐私的目录。

## 目录结构

```
LanFileShare/
├── .github/workflows/build.yml   # GitHub Actions 自动编译
├── app/
│   ├── build.gradle              # 应用模块配置（Ktor 服务器依赖）
│   └── src/main/
│       ├── assets/index.html     # 网页端界面（单文件，无外部依赖）
│       ├── java/com/lanshare/filesync/
│       │   ├── MainActivity.kt        # 主界面：启停/目录/权限/地址
│       │   ├── FolderPickerActivity.kt# 内置目录选择器
│       │   ├── ServerService.kt       # 前台服务 + 唤醒锁
│       │   └── LanFileServer.kt       # Ktor 内嵌 HTTP 服务器（全部接口）
│       ├── res/                   # 界面资源与图标
│       └── AndroidManifest.xml
├── build.gradle / settings.gradle / gradle.properties
└── README.md
```

## 技术说明

- 原生 Kotlin + Ktor 2 (CIO) 内嵌 HTTP 服务器，端口 8080，监听所有网卡
- minSdk 24（Android 7.0+），targetSdk 34
- 所有文件操作都做了目录穿越防护，只能访问共享目录内部
- zip 打包采用流式输出，大文件夹不会占用大量内存
